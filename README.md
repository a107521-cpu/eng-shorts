# Eng Shorts

재밌는 영어 쇼츠를 위아래로 끝없이 넘겨 보면서, 영어·한글 자막을 영상 아래에 띄워 주는 개인 학습용 웹앱이에요.

**열기:** https://a107521-cpu.github.io/eng-shorts/

휴대폰 홈 화면에 추가하면 앱처럼 전체 화면으로 열려요.
- iPhone (Safari): 공유 버튼 → **홈 화면에 추가**
- Android (Chrome): ⋮ 메뉴 → **홈 화면에 추가**

## 쓰는 법

| 동작 | 하는 일 |
|---|---|
| 영상 위로 밀기 / 아래로 밀기 | 다음 영상 / 이전 영상 |
| 영상 한 번 누르기 | 멈춤 · 재생 |
| 자막의 단어 누르기 | 한국어 뜻 + 발음 듣기 |
| 아래 자막 목록에서 문장 누르기 | 그 문장부터 다시 재생 |
| 영상과 자막 사이 막대 끌기 | 영상 / 자막 크기 조절 |

자막 아래 도구 줄: **이전 줄 · 한 줄 반복 · 속도(1× / 0.75× / 0.5×) · 영어 가리기 · 한글 켜고 끄기 · 저장 · 다음 줄**

저장한 문장은 오른쪽 위 ☆ 버튼에 모여요. ▶를 누르면 그 장면부터 다시 볼 수 있어요.

⚙ 설정에서 볼 영상 종류(코미디, 길거리 인터뷰, 토크쇼, 리액션, 음식, 동물, 상식·과학, 스포츠)를 고르거나, 좋아하는 채널을 직접 추가할 수 있어요. "문장마다 멈추기"를 켜면 한 문장이 끝날 때마다 멈춰요.

## 영상은 어디서 오나요

영어로 말을 많이 하는 인기 채널 45개(Smosh, Jubilee, Jimmy Fallon, Max Fosh, Nick DiGiovanni 등)의 쇼츠를 YouTube 공식 플레이어로 섞어서 보여줘요. 채널당 최근 쇼츠를 최대 200개 정도 가져와서, 볼수록 더 많은 채널에서 모아요. 본 영상은 기억해 두고 다시 나오지 않아요.

## 자막 서버 연결하기

옆(아래) 자막은 YouTube 자막을 가져와서 보여주는데, 브라우저 보안 규칙 때문에 웹페이지가 YouTube 자막을 직접 읽을 수 없어요. 그래서 자막을 대신 가져다 주는 작은 서버가 필요해요. Cloudflare에서 무료로 만들 수 있고 5분 정도 걸려요.

1. https://dash.cloudflare.com 에 가입하고 로그인해요. (무료 플랜이면 충분해요)
2. 왼쪽 메뉴 **Compute (Workers)** → **Workers & Pages** → **Create** 를 눌러요.
3. **Start with Hello World!** 를 고르고, 이름을 `eng-shorts-subs` 로 정한 뒤 **Deploy** 를 눌러요.
4. **Edit code** 를 누르고, 원래 있던 코드를 전부 지운 다음 이 저장소의 [`worker/worker.js`](worker/worker.js) 내용을 그대로 붙여넣고 **Deploy** 를 눌러요.
5. 화면에 나오는 주소를 복사해요. 예: `https://eng-shorts-subs.내계정.workers.dev`
6. 앱에서 ⚙ 설정 → **자막 서버** 칸에 붙여넣고 **연결 확인** 을 눌러요. "자막 서버에 연결됐어요"가 나오면 끝이에요.

무료 플랜은 하루 10만 번 요청까지 쓸 수 있어서 혼자 쓰기엔 충분해요.

자막 서버가 없을 때는 공개 Invidious 서버에서 자막을 가져와 보고, 그것도 안 되면 영상 화면 안에 YouTube 영어 자막(CC)을 켜 줘요.

## 알아둘 점

- 한글 자막은 영어 자막을 Google 번역으로 옮긴 거예요. 자동 생성 영어 자막은 가끔 틀릴 수 있어요.
- YouTube가 클라우드 서버에서 오는 자막 요청을 막을 때가 있어요. 그런 영상은 영상 안 CC 자막으로 대신 보여줘요.
- 채널이 외부 재생을 막아 둔 영상은 자동으로 건너뛰어요.
- 본 영상 기록과 저장한 문장은 지금 쓰는 기기의 브라우저에만 저장돼요.

## 파일

- `index.html` — 앱 전체 (HTML/CSS/JS 한 파일)
- `worker/worker.js` — 자막 서버 (Cloudflare Worker)
- `manifest.webmanifest`, `icon*.png`, `icon.svg` — 홈 화면 아이콘
